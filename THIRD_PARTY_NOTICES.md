## Data and literature

No third-party datasets are bundled. CORTEX parameters use published effect directions and summary statistics cited in `src/lib/evidence/sources.ts`; no participant-level recordings (including BBBD) are ingested. Oriane API responses are fetched at runtime under the operator's own Oriane API key and are not redistributed; `docs/oriane/openapi.snapshot.json` is a snapshot of Oriane's public API schema kept for type reference.
